# My TV identity

Approved TV-and-play symbol in lime (`#D5F58A`) on ink (`#0B1017`). The wordmark pairs white (`#F3F6FA`) “My” with lime “TV”.

- `my-tv-symbol.svg`: transparent, scalable symbol.
- `my-tv-logo.svg`: horizontal logo with the My TV wordmark, intended for dark backgrounds.
- Android uses the matching vector in `ic_my_tv_logo.xml` for in-app branding and a centered, safe-area-scaled foreground for adaptive and themed launcher icons.

The public app name is **My TV**. Version 0.5.0 adopts Android application ID `com.extreme.mytv`, requiring one fresh installation and sign-in for users of the older package. Subsequent releases retain this ID and the signing identity for in-place updates. See [Android updates](../android-updates.md).
