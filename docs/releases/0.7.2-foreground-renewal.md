# My TV 0.7.2

Fixes renewal screens remaining on the loading state until the phone is put to sleep and woken again.

The quote was received and application state updated, but the old Compose runtime could leave the visible screen stale. The runtime is now updated to 1.9.2. An automated foreground UI regression reproduces the failure with the previous runtime and verifies payment-method selection, asynchronous quote arrival, confirmation, and the enabled Square checkout button with this update, without pausing or resuming the activity.

Install over the existing My TV app. Saved login is retained. No Website host or Auth-worker host update is needed. Payment verification rules are unchanged; a live merchant payment still requires device acceptance.
