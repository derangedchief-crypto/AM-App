# My TV 0.7.1

- Opening an existing renewal now takes you to its invoice after payment-method selection, including repeated attempts to open the same order.
- Pending checkout results are immediately available without waiting for another account and order-list refresh.
- Renewal errors scroll into view rather than remaining above the visible screen.

Install the APK update over My TV 0.7.0. Existing saved login is retained. No Website host or Auth-worker host update is needed for these app changes.

The invoice provides the secure payment-provider checkout button when a checkout URL is available. Orders requiring provider review remain visible with their retry action. This release does not change payment verification or automatically mark a renewal paid.
